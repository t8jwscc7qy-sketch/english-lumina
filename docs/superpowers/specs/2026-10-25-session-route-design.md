# Маршрут дня: сессия, минуты, «минимальный день» и серия

## Зачем

Продукт ведёт ежедневную сессию: карточки на сегодня → упражнения на слабые темы (с повторами ошибок) → итог дня. Сейчас на «Сегодня» серия и «Минимальный день» — демо-данные, кнопка «Начать сессию» отключена, и пользователю самому приходится решать, чем заниматься. Маршрут убирает это решение: нажал одну кнопку, прошёл шаги, увидел честный итог. Серия и «минимальный день» считаются из журнала событий (он и задуман как источник серий и вех).

Решено с пользователем 2026-10-25: минуты считаются по времени между ответами; минимальный день 10 минут; серия с мягкой заморозкой (один пропущенный день на любые 7 суток прощается); не больше 10 карточек за сессию; «Закончить» доступно всегда.

## Данные: минуты, минимальный день, серия

Только из `events` (новых таблиц нет). Учитываются события `card.reviewed` и `exercise.answered` (повторы ошибок входят в `exercise.answered`).

- **Минуты** (чистая функция `activity.Minutes(times []time.Time) time.Duration`): времена отсортированы по возрастанию; ответ добавляет `t_i − t_{i−1}`, если пауза не больше 60 секунд; иначе (и для первого ответа) добавляется фиксированные 20 секунд. Длинная пауза не накручивает минуты, одиночные ответы не дают ноль.
- **Сутки**: в часовом поясе из настроек (по умолчанию UTC), границы `mistakes.DayStart`. Ответы считаются в сутки, где произошёл ответ; серия пауз не склеивается через полночь (пауза через границу суток = новый день, первый ответ нового дня даёт 20 секунд).
- **Минимальный день**: 10 минут активности за сутки (константа `MinimumDayMinutes = 10`). `dailyMinutes` из настроек остаётся целью дня и показывается отдельно.
- **Серия** (чистая функция `activity.Streak(dayMinutes map[civilDay]time.Duration, today civilDay) Streak`): число подряд идущих суток с выполненным минимальным днём, считается назад от вчера; сегодняшние сутки добавляются, если минимум уже выполнен, и не обнуляют серию, пока не закончились. **Заморозка:** один пропущенный день прощается, если в предыдущие 6 суток не было другого прощённого пропуска; второй пропуск в окне 7 суток обрывает серию. Результат: `{ Days int; FreezeUsedOn *civilDay }`, где `FreezeUsedOn` — последний прощённый день, который попал в серию.
- Просмотр истории: события за последние 60 суток (запрос по индексу `events_user_type_occurred`); серия не превышает 60.

## API (сначала `api/openapi.yaml`)

`GET /api/v1/progress/today` → `{ minutes, minimumDay, goalMinutes, doneToday, streakDays, freezeUsedOn, today: { answers, correct, cardsReviewed, mistakesOpened, mistakesClosed } }`.
- `minutes` — вещественное число минут за сегодня (одна десятая), `minimumDay = 10`, `goalMinutes` из настроек (если настроек нет — 15), `doneToday = minutes >= minimumDay`.
- `today` считается из событий за сутки: `answers` и `correct` — по `exercise.answered` (`payload.correct`), `cardsReviewed` — по `card.reviewed`, `mistakesOpened`/`mistakesClosed` — по `mistake.opened`/`mistake.closed`.
- Ответ 401 без входа; ничего не пишется.

## Интерфейс

- **«Сегодня»**: карточки «Серия» и «Минимальный день» показывают настоящие данные (`XpBar`, «N из 10 мин», «M дней», пометка «заморозка использована» при `freezeUsedOn`). Плашка «Демо-данные» остаётся у блоков, которые ещё демо (линия пути, прогноз). Кнопка меняется: «Начать сессию» (минут нет), «Продолжить сессию» (0 < минут < 10), «Позаниматься ещё» (минимум выполнен) и ведёт на `/session`.
- **Страница `/session`**: сверху полоса из 10 сегментов и «N из 10 мин» (`role="progressbar"` или текст), кнопка «Закончить» всегда доступна. Шаги:
  1. **Карточки**: если есть карточки на повторение (`/cards/queue`), по одной, не больше 10 за сессию (счётчик «Карточка 3 из 10»); нет карточек — шаг пропускается без экрана.
  2. **Упражнения**: обычный `GET /exercises/next` (повторы ошибок подмешиваются самим подбором). Идёт, пока минуты не дойдут до 10; затем экран «Минимум на сегодня выполнен»: «Закончить» или «Ещё немного».
  3. **Итог дня**: минуты, число ответов и доля верных, открыто и закрыто ошибок, серия (и заморозка), кнопки «На главную» и «Ещё немного».
- Карточки и упражнения выделяются из страниц `CardsPage` и `ExercisesPage` во встраиваемые компоненты (`ReviewCard`, `ExerciseCard` с колбэком «шаг выполнен»); поведение и клавиши (Пробел, Enter, 1–4) не меняются, страницы `/cards` и `/exercises` работают как раньше.
- Минуты обновляются после каждого ответа повторным запросом `/progress/today`. Закрытие вкладки ничего не теряет: прогресс лежит в событиях.
- Без движения (клавишные действия; «вспышка успеха» при минимальном дне в рамки не входит). `DESIGN.md` обновляется. Исполнитель фронтенда обязан вызвать навыки `impeccable`, `web-design-guidelines`, `emil-design-eng`.

## Тесты

- Чистые функции: `activity.Minutes` (пустой список = 0; один ответ = 20 с; пауза ровно 60 с считается, 61 с даёт 20 с; ответы за разные сутки не склеиваются), `activity.Streak` (нет данных = 0; подряд 3 дня; пропуск вчера прощается; два пропуска в 7 суток обрывают; сегодня без минимума серию не обнуляет; граница 60 суток; смена часового пояса).
- `httpapi` с поддельным хранилищем: пустой журнал → нули, `doneToday=false`; ответы за сутки → верные минуты и счётчики; чужие события не видны; сутки по поясу из настроек; нет настроек → UTC и `goalMinutes=15`; 401.
- Интеграция на настоящей Postgres во временной схеме: события за несколько суток → серия и минуты.
- Vitest: кнопка «Сегодня» в трёх состояниях; страница `/session`: пропуск шага «Карточки» без карточек, лимит 10, переход к упражнениям, экран «Минимум выполнен», «Закончить» в любой момент, итог дня; поведение `/cards` и `/exercises` не изменилось (существующие тесты проходят).
- Playwright: сессия целиком в подмене API, светлая и тёмная темы, 1440/1024/390 px, без горизонтальной прокрутки.

## Риски и ограничения

- Минуты — оценка по времени между ответами, а не время на экране: чтение предложения без ответа не засчитывается; быстрый ответ вслепую засчитывается как есть.
- Заморозка считается из событий, а не хранится: если события когда-либо удалят, серия пересчитается (журнал только для добавления).
- Серия смотрит назад на 60 суток; более длинная серия показывается как 60 (документировать в интерфейсе не нужно: порог далёкий).
- Часовой пояс берётся из настроек; поменял пояс — прошлые сутки пересчитаются по новому.
- Лимит 10 карточек: остальные ждут следующей сессии (в `/cards` по-прежнему можно пройти всё).
- Шаги страницы не хранятся на сервере: после перезагрузки сессия начнётся с шага, который определяют текущие данные (карточки на сегодня, минуты).

## Вне рамок

«Вспышка успеха» и анимации при минимальном дне; вехи и «босс недели»; линия пути и прогноз; настройка длины сессии и лимита карточек; уведомления.
