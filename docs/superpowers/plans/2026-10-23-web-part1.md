# Фронтенд, часть 1: каркас, дизайн-система, вход, оболочка

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Пользователь входит через настоящий API и видит оболочку Verst с экраном «Сегодня» в стиле «Пиксельный квест».

**Architecture:** React-приложение в `web/` говорит с Go по контракту `api/openapi.yaml` (типы TS генерируются). Дизайн-токены в CSS-переменных Tailwind, две темы, пиксельные примитивы поверх shadcn/ui. Состояние сервера в TanStack Query.

**Tech Stack:** Vite, React, TypeScript, Tailwind CSS, shadcn/ui, Motion, TanStack Query, Sonner (из CLAUDE.md); дополнительно (одобрено пользователем «делай фронтенд дальше»): react-router, openapi-typescript, @fontsource (Pixelify Sans, Onest), Vitest.

**Spec:** `.impeccable/surfaces/web.md` (бриф и контракт направления), `PRODUCT.md`, проектный документ.

## Global Constraints

- Сетка 4px; контуры 4px; тени жёсткие (без blur); без градиентов и эмодзи в интерфейсе.
- Пиксельный шрифт (Pixelify Sans) только для заголовков и крупных чисел, текст Onest; шрифты свои через `@fontsource`, без CDN.
- Цвета: ночной синий #1E2347, небесный #4CC9F0, трава #52B788, солнечный #FFD23F, коралл #EF476F, бумага #F7F7FF. Жёлтый — опыт и главное действие, коралл — только ошибки, зелёный — пройдено, голубой — «ты здесь».
- Две темы (светлая, тёмная), по умолчанию как в системе; `prefers-reduced-motion` отключает анимации.
- Интерфейс на русском, на «ты». Вёрстка без фиксированной ширины.
- `dangerouslySetInnerHTML` запрещён. Контракт API меняется сначала в `openapi.yaml`; сгенерированный код руками не правим.
- Перед использованием библиотеки сверять API через Context7. Коммиты маленькие, перед ними тесты и линтеры.

## Review Focus

- Логин с ошибкой сети, `429`, `503`, `400`, `401`: понятное сообщение, форма не зависает.
- Фокус с клавиатуры на всех интерактивных элементах и видимый пиксельный фокус.
- Очень узкое и очень широкое окно (900–2000px): вёрстка не ломается.
- Сессия истекла во время работы (`401` на любом запросе): возврат на экран входа без белого экрана.
- Переключение темы не мигает и сохраняется.
