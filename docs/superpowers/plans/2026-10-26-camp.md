# «Привал» (этап B) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (Native, выбран пользователем). Шаги с чекбоксами `- [ ]`.

**Goal:** упражнения режима «Привал» берут только предложения, где не меньше `camp_coverage` слов (по умолчанию 95 %) уже изучены; раздел `/camp` показывает, открыт ли режим.

**Architecture:** чистая функция `exercises.Coverage(tokens, known)` + множество известных словоформ, собираемое один раз на запрос из `word_learning` (`learned`, `known_at_start`). `GET /exercises/next?mode=camp` кладёт фильтр в контекст запроса; общий помощник `s.campOK(ctx, tokens)` вызывается в циклах кандидатов («пропуск» по грамматике и по уровню, «порядок слов», «перевод», «выбор формы»). «Сопоставление» в «Привале» берёт слова только из изученных. Миграций нет.

**Tech Stack:** Go, sqlc, OpenAPI, React, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-26-learn-camp-design.md`, раздел «Привал».

## Global Constraints
- `campMinWords = 50`: «Привал» открыт, когда изучено (`learned` + `known_at_start`) не меньше 50 слов; иначе `GET /exercises/next?mode=camp` отвечает `404 camp_closed`, экран говорит «Привал откроется после N слов».
- Покрытие: имена собственные не в начале предложения и числа в знаменатель не входят; предложение целиком из известных слов годится.
- Параметр `mode` читается из строки запроса вручную (объявленный query-параметр тянет зависимость); любое значение кроме `camp` — обычный режим; без параметра поведение прежнее.
- Банк ошибок, рейтинги и события работают как раньше (упражнение то же, меняется только отбор).
- Новых зависимостей нет. Интерфейс на русском.

## Review Focus
- Пустой или маленький набор известных слов: режим закрыт, а не пустой `404 no_exercise`.
- Известное слово в другой форме (`ran` при известном `run`) считается известным; слово с совпадающими леммами разных частей речи.
- Повторы ошибок в «Привале» выдаются как обычно (повтор не фильтруется покрытием: это копия сохранённого упражнения).
- Производительность: множество форм для 5 000 слов строится быстрее 50 мс; запрос известных слов один на вызов.
