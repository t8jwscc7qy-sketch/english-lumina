# Каталог крупных источников данных для Verst

Дата: 2026-10-26. Проверено поиском (лицензии и размеры по найденным страницам; точные условия каждого файла сверять в день загрузки). Правило проекта: каждый источник — отдельный модуль `internal/sources/<имя>` по навыку `new-source`, с лицензией и атрибуцией на странице «Источники».

Важное про лицензии: **CC BY-SA** требует указать автора и распространять производные данные под той же лицензией. Пока база остаётся личной (файлы данных в git не коммитятся), это только строка атрибуции; при публичной раздаче данных производные тоже будут CC BY-SA.

## Уже загружены

CEFR-J (слова A1–B2), Octanove (C1–C2, CC BY-SA 4.0), Tatoeba (предложения, CC BY 2.0 FR), FrequencyWords en/ru (CC BY-SA 4.0), FreeDict eng-rus (CC BY-SA 3.0, шумный).

## Уровень 1: берём в первую очередь

### 1. Wiktionary через Kaikki.org (Wiktextract) — самый ценный
- **Что:** разобранный английский Викисловарь: значения с определениями, **переводы на русский по значениям** (поле `translations`, код `ru`), **транскрипция IPA и ссылки на звуковые файлы** (поле `sounds`), словоформы, синонимы и антонимы, примеры, этимология, **пометки** (`obsolete`, `dated`, `vulgar`, `slang`, `informal` и др.). [kaikki.org: сырые данные](https://kaikki.org/dictionary/rawdata.html)
- **Размер:** сырой JSONL ≈ 24,8 ГБ (2,9 ГБ в `.gz`), обновляется примерно раз в неделю; русская редакция отдельно (`ru-extract.jsonl.gz`, ≈ 295 МБ, определения по-русски). Берём потоком и оставляем только наши леммы (десятки тысяч строк).
- **Лицензия:** CC BY-SA и GFDL (как у Викисловаря); код Wiktextract MIT. Просят процитировать Ylonen, LREC 2022.
- **Что даёт нам:** (а) качественные переводы **с привязкой к значению** и фильтром устаревших и грубых слов (лечит «батюшка», «сосать», «одёжа»); (б) IPA без CMUdict; (в) настоящие формы слов вместо наших правил (`internal/words`); (г) синонимы и антонимы для правила «не ставить близкие слова рядом»; (д) определения для уроков слов; (е) примеры.
- **Риск:** размер скачивания и сложность формата; нужен аккуратный разбор значений.

### 2. Звук примеров Tatoeba
- **Что:** живая озвучка части предложений, которые у нас уже есть. Файл с id предложений со звуком на странице загрузок, звук забирается скриптом с `audio.tatoeba.org`. [Загрузки Tatoeba](https://tatoeba.org/en/downloads)
- **Лицензия:** **у каждой записи своя** (CC BY-NC 4.0 чаще всего, у части CC BY, есть и CC BY-NC-ND). Для личного проекта допустимо в рамках лицензии записи; брать только записи с лицензией, разрешающей наше использование, и хранить автора. Массового архива лицензий нет, их придётся фильтровать.
- **Что даёт:** диктант на слух и озвучка примеров настоящими голосами.

### 3. Open English WordNet
- **Что:** сеть значений: синонимы (наборы), гиперонимы («cat — animal»), антонимы, части-целое. 161 705 слов, 120 630 наборов, 419 тысяч связей (издание 2024). [Open English WordNet](https://github.com/globalwordnet/english-wordnet)
- **Лицензия:** CC BY 4.0 (самая простая). Форматы: XML, RDF, WNDB; издание 2025 Plus в JSON.
- **Что даёт:** смысловая близость слов (развести `big/large/huge` по разным блокам), «слова по темам» через гиперонимы, упражнения «лишнее слово», подсказки «синоним».

### 4. Тексты для чтения и слушания (по уровням)
- **VOA Learning English:** тексты, звук и видео **в общественном достоянии**, можно использовать в учебных и коммерческих целях с указанием источника. Исключения: материалы агентств (AP, Reuters, AFP), чужие вставки; название и логотип VOA нельзя коммерчески. Просят писать на `learningenglish@voanews.com`. [Условия](https://learningenglish.voanews.com/p/6021.html), [запрос контента](https://learningenglish.voanews.com/p/6861.html). Это простой язык с контролируемым словарём, хорошие уровни A2–B1.
- **OneStopEnglish:** 189 статей The Guardian в трёх версиях (elementary/intermediate/advanced), переписаны преподавателями, **CC BY-SA 4.0**; всего 567 текстов. [Репозиторий](https://github.com/nishkalavallabhi/OneStopEnglishCorpus) Подходит для B1–B2 и для сравнения «тот же текст на разных уровнях».
- **Simple English Wikipedia:** тексты **CC BY-SA 4.0** (дампы на `dumps.wikimedia.org/simplewiki`, около 200 МБ в архиве). Много простых предложений для покрытия слов и тематические категории.
- **Что даёт:** «чтение» из изученных слов (раздел 95–98 % покрытия), аудирование (VOA со звуком), тексты по уровням.
- **Риск:** нужен разбор HTML (VOA), проверка покрытия и «запретных» вставок агентств; уровни VOA не размечены по CEFR (оценим сами по словам).

## Уровень 2: полезно, но позже

### 5. Mozilla Common Voice (английский)
- **Что:** озвученные предложения с расшифровкой, **CC0**; весь корпус более 31 тысячи часов на 129 языках, английский самый большой (точные цифры по релизу сверять). Отдаётся как MP3 плюс TSV, проверенные записи помечены. [Common Voice](https://www.mozillafoundation.org/en/blog/common-voice-18-dataset-release/)
- **Что даёт:** диктант и слушание многими голосами и акцентами. Нужны только проверенные клипы из наших изученных слов (несколько тысяч), а не весь архив.
- **Риск:** загрузка через сайт Mozilla (согласие с условиями), большие файлы.

### 6. OpenMoji (картинки)
- **Что:** более 4 тысяч цветных SVG-пиктограмм, **CC BY-SA 4.0** (код LGPL-3.0); нужна атрибуция «All emojis designed by OpenMoji…». [OpenMoji](https://github.com/hfg-gmuend/openmoji)
- **Что даёт:** двойное кодирование для конкретных слов (apple, house, dog) без поиска фото; сопоставление слова и картинки.
- **Риск:** покрывает только конкретные существительные; сопоставление слов с эмодзи нужно делать по названиям Unicode.

### 7. NGSL и CEFR-J Grammar Profile (описаны в методике)
- NGSL: 2 809 базовых слов, **CC BY-SA 4.0**, ≈ 92 % покрытия обычного текста. CEFR-J Grammar Profile: список грамматики A1–B2, бесплатно с атрибуцией. Дают каркас уроков.

### 8. CMUdict (запасной источник произношения)
- BSD-2-Clause (версия 0.7b), ARPAbet → IPA; нужен только если Kaikki не даст IPA для слова.

### 9. Google Books Ngrams
- **CC BY 3.0**, включая коммерческое использование; есть теги частей речи (`_VERB_`, `_ADP_`), годятся для **коллокаций и фразовых глаголов**. Объём огромный (терабайты), нужен предварительный отбор; «синтаксические» n-граммы под NC-лицензией, их не брать. [Google Books Ngrams](http://storage.googleapis.com/books/ngrams/books/datasetsv3.html)

### 10. Open textbooks по английскому (проверка и подача)
- **ESL.Wiki** (CC BY-SA), материалы BCcampus/LibreTexts (в основном CC BY-SA, но у каждой книги своя лицензия: сверять). Годятся для **сверки** моих шпаргалок и идей подачи; дословно копировать нельзя без выполнения условий лицензии (атрибуция и та же лицензия).

## Уровень 3: ограниченно

- **CEFR-SP** (17 тысяч предложений с уровнем): лицензия смешанная, Newsela закрыта, часть CC BY-NC-SA, часть CC BY-SA 3.0; брать только свободные подмножества, после чтения README. Нужен для калибровки оценки уровня предложений. [CEFR-SP](https://github.com/yukiar/CEFR-SP)
- **LibriSpeech и LibriVox:** общественное достояние и CC BY 4.0, очень много аудио, но язык художественной литературы XIX–XX века и размер; только для продвинутых уровней.
- **ConceptNet:** CC BY-SA 4.0, знания о мире («cat — IsA animal»), для упражнений вроде «что это?» полезнее WordNet. [ConceptNet: условия](https://github.com/commonsense/conceptnet5/wiki/Copying-and-sharing-ConceptNet)

## Не использовать (или только с разрешением)

Oxford 3000/5000, English Vocabulary Profile, **English Grammar Profile** (условия не найдены), Cambridge Dictionary, BBC Learning English, подписочные учебники и приложения, общие колоды Anki без явной лицензии, Forvo, субтитры OpenSubtitles как текст (из них у нас только частоты). Материалы агентств внутри VOA (AP, Reuters, AFP).

## Предлагаемый порядок подключения

1. **Kaikki (Wiktextract)** как источник `wiktionary-en`: определения, русские переводы по значениям, IPA, формы, синонимы, пометки. Закрывает качество переводов, произношение и смысловую близость сразу и меняет качество «Знакомства».
2. **Open English WordNet** как `oewn`: близость слов, темы.
3. **Tatoeba audio** (с фильтром лицензий): диктант и озвучка.
4. **NGSL + CEFR-J Grammar Profile**: каркас этапов.
5. **VOA, OneStopEnglish, Simple English Wikipedia**: чтение и слушание.
6. **OpenMoji**: картинки.
7. **Common Voice**: голоса для диктанта.
8. Ngrams и остальное по мере надобности.

Каждый шаг — отдельный подпроект со спеком (по правилам проекта: размеры и время импорта меряем на этапе плана).
