# StoryWeaver как дополнительный источник текстов: оценка (2026-10-26)

Только оценка, без реализации. Источники: [Pratham Books: лицензии](https://prathambooks.org/cc/), [поиск по StoryWeaver и условиям](https://storyweaver.org.in/about), код платформы [PrathamBooks/StoryWeaverOpen](https://github.com/PrathamBooks/StoryWeaverOpen), пример клиента [sushi-chef-pratham-books-storyweaver](https://github.com/learningequality/sushi-chef-pratham-books-storyweaver/blob/master/chef.py), список фильтров публичного эндпоинта `/api/v1/books/filters`.

## Лицензия
- Книги в основном **CC BY 4.0**: можно читать, скачивать, переводить, адаптировать, перерабатывать, в том числе коммерчески; нужно указать Pratham Books, донора/издателя книги, автора, иллюстратора и переводчика, если они есть.
- **Исключения:** «Readalong» и видео — CC BY-NC-ND 4.0 (брать нельзя); у части старых книг CC BY 3.0 или **CC BY-SA 3.0** (производные данные тоже под SA). Страница Pratham Books противоречиво называет CC0 и «CC 4.0», поэтому **лицензия проверяется у каждой книги**, а не у платформы целиком.
- Иллюстрации под той же лицензией, но нам не нужны.

## Формат и доступ
- Официальных условий на программный доступ и документации API я не нашёл. Есть неофициальный JSON-интерфейс платформы (`/api/v1/books-search`, `/api/v1/stories/{id}/read`), которым пользуются сторонние проекты; фильтры: язык, уровень (Level 1 «для начинающих», 1, 2, 3, 4), категория, издатель, тип производной (оригинал, перевод, пере-уровень), тип истории (Read, Readalong, Gif). Поля «лицензия» в фильтрах нет.
- Для скачивания по книгам есть web-PDF, печатный PDF и ePub. Исходный код платформы (Rails + React) открыт под MIT.
- Условия использования страницы `terms-of-use` по адресу не открылись (404), поэтому разрешение на автоматический сбор надо **запросить у Pratham Books письмом** до реализации.

## Как подключать (если разрешат)
1. Новый источник `internal/sources/storyweaver` по контракту `Fetch → Parse → Load` (правило проекта): скачать список английских оригиналов Level 1–4, для каждой книги прочитать страницы с текстом, сохранить лицензию и участников книги; книги с NC/ND и неизвестной лицензией пропускать.
2. Предложения из страниц; каждый текст — `texts.kind = 'open'` с `slug`, уровнем по **своему подсчёту покрытия** (их Level 1–4 не равны нашим уровням словаря).
3. Выбор как у авторских текстов: по понятности для словаря пользователя; склейка остаётся запасной.
4. Атрибуция: у каждого текста строка «Pratham Books, StoryWeaver, CC BY 4.0, автор, иллюстратор, переводчик», в «Источниках».

## Что мешает
- **Перевода на русский нет**: у наших текстов к каждому предложению есть перевод для подсказок. Для StoryWeaver его пришлось бы или не показывать, или добавлять самим (книги на русском есть не у всех, выравнивание предложений сложное).
- Контекст детский и индийский: темы и слова не всегда из нашего частотного списка, часть текстов длиннее 150 слов и с редкими словами; покрытие будет ниже 80 % для небольших словарей.
- Лицензия разная у разных книг, сбор должен быть осторожным; неофициальный API может измениться.
- Нужна ручная выборка и проверка качества (пользователь «сверяет выборочно»).

## Вывод
Подключать **можно как дополнительный источник для уровней от ≈1000 слов** (книги Level 3–4, где словарь шире), **после** письменного разрешения Pratham Books и при условии, что перевод предложений будет необязательным (кнопка «Перевод» скрыта, слова с подсказками остаются).
