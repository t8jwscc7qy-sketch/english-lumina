# Design System: Verst

## Overview

**Creative North Star: "Спокойный премиум с игровыми вспышками"**

Интерфейс спокойный и взрослый: один гротеск Onest, тонкие рамки в 1px, мягкие тени, скругления 12-16px, линейные иконки. Характер даёт не декор, а несколько фирменных вещей, нарисованных пикселями: логотип «Платформер» 1A, маскот «Верста» (полосатый столбик-веха с лицом), флаги этапов и дизер-мост на карте пути. Путь A1…C1 нарисован картой этапов, неопределённость прогноза показана точечным растром, а не выдуманной датой.

Интерфейс на русском, на «ты». Плотность умеренная: крупные блоки на воздухе, числа крупные и жирные. Это решение смягчило прежний «Пиксельный квест»: от него на карте этапов остались дизер и платформы, а шрифты Press Start 2P и Pixelify Sans удалены.

Отвергнутое: детский мультяшный вид и шаблонный учебный дашборд с кольцом прогресса. Игровое проявляется вспышками успеха (в сборке пока не реализованы).

**Key Characteristics:**
- Один шрифт, Onest 400/600/700; заголовки и числа 700.
- Рамка 1px, скругления 12-16px, мягкие тени, сетка 4px.
- Пиксель-арт только в логотипе, маскоте, флагах и дизер-мосте карты этапов.
- Цвета с одной задачей; две темы (бумага и ночь) с одним набором ролей.
- Движение сдержанное; маскот качается покадрово `steps(2)`; `prefers-reduced-motion` выключает анимации.

## Colors

Ночной синий и бумага как каркас, четыре сигнальных цвета, у каждого одна задача.

### Primary
- **Солнечный жёлтый** (sun): только опыт и главное действие: кнопка по умолчанию, заполненные сегменты шкалы опыта, выделение текста и `accent-color` нативных контролов. Не для декора, не для предупреждений, не для плашки «демо».

### Secondary
- **Небесный голубой** (sky): «ты здесь»: платформа текущего уровня; кольцо фокуса в тёмной теме и всегда на тёмной панели. Акцентная кнопка (accent) использует его же.
- **Трава** (grass): пройдено; платформы и флаги пройденных уровней.
- **Коралл** (coral): только ошибки: рамка поля с `aria-invalid`, рамка сообщения об ошибке, иконка карточки ошибок. Для текста темнее (coral-text; в тёмной теме светлее, чтобы держать 4.5:1). Заливка опасной кнопки мягче (coral-soft): на ней читается чернильный текст.

### Neutral
- **Ночные чернила** (ink): текст и кольцо фокуса в светлой теме, левая панель (rail), контур пиксель-арта.
- **Бумага** (paper): фон светлой темы; карточки белые (card).
- **Ночь** (night): фон тёмной темы; карточки card-dark, панель rail-dark.
- **Приглушённая поверхность** (surface-muted): будущие платформы, фон шкалы, hover вторичных элементов, заливка disabled-кнопки.
- **Приглушённый текст** (text-muted): подписи и подсказки.
- **Рамка** (border): тонкая рамка карточек и разделителей; оформление, не контрол.
- **Рамка поля** (field-border): рамка полей ввода и вторичной кнопки, контрастнее обычной (не ниже 3:1 к белому).
- **Мост** (bridge): точки дизера на «неопределённом» участке пути; обычная трава на платформе тонет.
- **Контур пиксель-арта** (`--pixel-ink`): ink в светлой теме, светлее (pixel-ink-dark) в тёмной, иначе маскот и флаги сливаются с карточкой.

### Named Rules
**The One Job Rule.** Каждый сигнальный цвет значит одно. Жёлтый не метка «демо» и не предупреждение; коралл не акцент и не декор; зелёный не «успех кнопки»; голубой не кнопка главного действия.
**The Ink Focus Rule.** Кольцо фокуса 2px: ink в светлой теме, sky в тёмной; в тёмной панели всегда sky.

## Typography

**Display, Body, Label:** Onest (system-ui, sans-serif), веса 400, 600, 700, локально через Fontsource.

**Character:** Один спокойный современный гротеск с хорошей кириллицей; иерархию делают вес и размер, а не смена гарнитуры.

### Hierarchy
- **Display** (700, 36px/44px, -0.02em): большие числа на карточках задач и серия на узком экране (`text-display`, `tabular-nums`).
- **Title** (700, 24px/32px, -0.01em): заголовки страницы и блоков («Привет, …», «Твой путь», «Вход»); на узких окнах «Серия» в Title, от `md` в Display.
- **Body** (400, 16px/24px): основной текст.
- **Button / menu** (600, 16px): подписи кнопок и пункты меню (sm кнопка 14px).
- **Label** (600, 14px/20px): заголовки малых карточек, подписи, плашка демо; подсказки 14px/400.

### Named Rules
**The Single Face Rule.** Один шрифт Onest на всём; новая гарнитура для акцента не вводится. Размеры из шкалы 12 / 14 / 16 / 20 / 24 / 36.

## Layout

Гибкая вёрстка без фиксированной ширины, сначала десктоп. Шаг 4px, основной ритм 8/16/24/32. Каркас: слева тёмная панель 240px (от `lg`, 1024px), ниже сжимается до 80px с одними иконками; рабочая область занимает остаток. Экран «Сегодня»: одна колонка, от `xl` (1280px) правая колонка 20rem с серией, минимальным днём и главной кнопкой; три карточки задач в ряд от `md`. Отступы страницы 24px, от `xl` 32px. Вход: центрированный блок до 28rem. «Перейти к содержимому» первой в порядке фокуса. Числа с `tabular-nums`. На узких окнах (390px) карта этапов уменьшает спрайты и прячет подписи, кроме «Ты здесь».

## Elevation & Depth

Гибрид: тонкая 1px рамка плюс мягкая рассеянная тень; тональных слоёв почти нет, тёмная тема использует более плотные тени на более светлой карточке.

### Shadow Vocabulary
- **Card** (`0 1px 2px rgb(30 35 71 / 0.05), 0 10px 28px -14px rgb(30 35 71 / 0.22)`; тёмная `0 1px 2px rgb(0 0 0 / 0.3), 0 12px 30px -14px rgb(0 0 0 / 0.6)`): класс `.surface`, все карточки и блоки.
- **Card hover** (`0 2px 4px rgb(30 35 71 / 0.06), 0 16px 34px -14px rgb(30 35 71 / 0.32)`; тёмная `0 2px 4px rgb(0 0 0 / 0.35), 0 18px 38px -14px rgb(0 0 0 / 0.75)`): карточка-ссылка при наведении.
- **Button** (`0 1px 2px rgb(30 35 71 / 0.18)`; тёмная `0 1px 2px rgb(0 0 0 / 0.4)`): жёлтая, акцентная и опасная кнопки; у disabled тени нет.

### Named Rules
**The Quiet Shadow Rule.** Тень мягкая и низкая, всегда в паре с рамкой 1px; жёстких смещённых теней нет.

## Shapes

Скругления 12px у кнопок, полей, плашек и пунктов меню; 16px у карточек (`.surface`); полные у шкалы опыта и участков карты. Рамка 1px (`--border`; у полей `--input`). Недоступное и «честная заметка» (демо) рисуются пунктирной 1px рамкой. Пиксель-арт (логотип, маскот, флаги, дизер) строится из клеток и остаётся острым; остальной интерфейс пикселей не использует.

## Components

### Buttons
- **Shape:** скруглённые 12px, Onest 600; высота 44px (sm 36px, lg минимум 48px, icon 44px).
- **Primary:** жёлтая с ink-текстом и тенью Button; одна на экран. Hover: затемнение `brightness-95`; нажатие сдвигает на 1px вниз.
- **Secondary / Accent / Destructive / Ghost / Link:** белая с рамкой field-border; голубая; coral-soft; прозрачная с hover-заливкой; ссылка с подчёркиванием.
- **Disabled:** приглушённая заливка (surface-muted), приглушённый текст, без тени. Так в сборке выглядит «Начать сессию» (сервис пока не подключён).
- **Фокус:** общее кольцо 2px.

### Inputs / Fields
- **Style:** 44px, белая заливка, рамка 1px field-border, скругление 12px, отступ 16px.
- **Focus:** общее кольцо 2px offset 2px.
- **Error:** рамка и дополнительная линия 1px в coral; сообщение: рамка coral, текст coral-text, `role="alert"`.
- **Disabled:** непрозрачность 50%.

### Cards / Containers
- **Surface:** белая (тёмная card-dark) заливка, рамка 1px, скругление 16px, тень Card, отступ 16px (крупные блоки 24px).
- **Карточка задачи:** целиком ссылка; линейная иконка 20px, заголовок 14px/600 приглушённый, число Display, подсказка 14px. Hover: подъём на 2px и тень Card hover за 150 мс. Иконка карточки ошибок в coral-text.

### Navigation
Левая панель цвета rail: логотип сверху, пункты 44px со скруглением 12px, линейная иконка lucide 20px (штрих 1.75) и подпись Onest 600. Активный: заливка `white/12`, светлый текст. Неактивный: rail-muted, на hover `white/6`. Ниже 1024px остаются иконки (подписи для скринридера). Внизу «Ты вошёл как …», переключатель темы и выход.

### Шкала опыта (XpBar)
Тонкая полоса 12px с полными скруглениями и сегментами с зазором 2px; заполненные sun, пустые полупрозрачный фон. 10 сегментов для минимального дня, 20 для опыта уровня. Прогресс только сегментами, колец нет.

### Карта этапов (StageMap)
Пять платформ A1…C1 встык (трек 12px): пройденные grass, текущий sky с маскотом (качается на 4px, `steps(2)`, 1.2с), участок до цели muted с дизером bridge, остальное muted. Над платформой пиксельный флаг; подписи «Пройден», «Ты здесь», «Цель». Под картой пометка «Собираю данные» с полоской дизера.

### Фирменный пиксель-арт
Логотип «Платформер» 1A (слово VERST стоит на земле; на узкой панели столб без лица), маскот «Верста», флаги, дизер (маска 8×8, `--bridge`). Это единственные пиксельные элементы; контур задаёт `--pixel-ink`.

### Выбор уровня (LevelPicker)
Группа обычных радиокнопок в `fieldset` с `legend`. Каждый вариант — строка с рамкой 1px field-border, скруглением 12px, кружком, кодом уровня Title и описанием простыми словами; выбранный: рамка `foreground` и заливка surface-muted, недоступный (цель ниже уровня): непрозрачность 50%. Фокус с клавиатуры: кольцо 2px вокруг всей строки. В режиме `compact` (страница «Настройки») уровни идут сеткой от 6.5rem без описаний, подпись 12px.

### Форма настроек и счётчик срока
Онбординг: три шага («Где ты сейчас?», «Куда идём?», «Сколько занимаешься?») внутри одной `.surface`, справа индикатор из трёх сегментов 6px (пройден grass, текущий sky, дальше muted) и «Шаг N из 3»; на узких окнах индикатор переносится под заголовок. Счётчик срока (`ForecastCounter`) стоит отдельной `.surface` справа от формы (от `lg`, 20rem, липкий), ниже формы на узких окнах. Внутри `role="status"` с Title («6–8 месяцев»), строкой «до B2 при 90 мин в день», вилкой месяцев финиша и сноской об оценке по часам Cambridge. Срок всегда вилка; предупреждение о нереальной дате (больше 4 часов в день) — coral-text.

### Источники и лицензии
Страница `/sources` (пункт меню «Источники», иконка весов): колонка до 3xl, на каждый источник отдельная `.surface` (`article`) с заголовком Title (имя источника и «версия N» Label приглушённым) и списком определений 14px: «Лицензия», «Автор данных» (атрибуция дословно), «Файл» (ссылка только на https, `target=_blank`, `rel=noopener`, показывается имя хоста), «Строк», «Загружено». От `sm` подписи слева в колонке 8rem, на узких окнах подпись над значением. Пустое состояние: одна `.surface` с командой импорта в `code` (фон surface-muted). Текст из базы только текстом, без разметки.

### Поиск слов
Страница `/words` (пункт меню «Слова»): колонка до 3xl, заголовок Title, абзац о том, что примеров предложений пока нет, поле `type="search"` с подписью «Слово» и фокусом при открытии. Результаты одним `.surface` со списком, строки разделены линией `--border`: слово 18px/600, часть речи 14px приглушённая, уровень в плашке (surface-muted, 14px/600, без сигнальных цветов), ниже строка оценок источников «CEFR-J B2 · Octanove C1» (14px приглушённая), строка «Частота: очень частое слово, № 870 из 50 000» (14px приглушённая; границы оценки: до 1 000 очень частое, до 5 000 частое, до 20 000 обычное, дальше редкое; слова нет в списке: «редкое слово, реже № 50 000») и заметки 14px. Над списком «Найдено: N» (`role="status"`); пока набирается следующий запрос, прежний список бледнеет (`opacity-60`, `aria-busy`). У каждого результата кнопка-призрак «Примеры» с шевроном (`aria-expanded`, шеврон поворачивается на 180°): по нажатию под словом раскрывается панель с до пятью примерами, подгружаемыми по требованию и кэшируемыми. Пример: английское предложение 16px с найденной формой в `<mark>` (surface-muted, 600, без жёлтого), русский перевод 14px приглушённый, строка атрибуции 12px «Tatoeba: #номер автор · #номер автор» со ссылками на tatoeba.org (подчёркнуты, `target=_blank`, `rel=noopener`). Диапазон подсветки считается в символах (кодовых точках), а не в единицах UTF-16. Состояния: подсказка до ввода, «Ищем…», «Ничего не найдено по «…»» с пояснением, что поиск идёт по началу слова, ошибка с «Повторить».

### Карточки слов
Страница `/cards` (пункт меню «Карточки»): колонка до 3xl, заголовок Title и справа «Осталось: N» (14px, приглушённый, `aria-live`). Одна карточка за раз в `.surface` (`article`): строка «уровень · часть речи» 14px; английское предложение 20px/400 с пропуском вместо слова (плашка surface-muted с `_____`, `role="img"`, `aria-label="пропуск"`), под ним русский перевод 16px приглушённый. **Лицо:** жёлтая кнопка «Показать ответ» (Пробел или Enter). **Оборот:** пропуск заменяется словом в `<mark>` (surface-muted, 600), под переводом атрибуция Tatoeba 12px (номера и авторы со ссылками), четыре кнопки оценки в сетке 2×2 (от `md` 4 в ряд): «Забыл», «Трудно», «Хорошо» (жёлтая, главное действие), «Легко»; под названием 12px «через 10 мин» (интервалы по ступеням: мин, ч, дн, мес., г.), клавиши 1–4. Пустая очередь: «На сегодня всё» в Title, число всех карточек и кнопка «Добавить слова». Карточка без предложения показывает слово крупно (Display), часть речи и уровень. Ошибка оценки: рамка coral-text под карточкой, кнопки остаются доступными (повтор идёт с тем же ключом идемпотентности).

На странице «Слова» у каждого результата рядом с «Примеры» кнопка «В карточки» (secondary, плюс слева); после добавления она становится неактивной ghost-кнопкой «В карточках» с галочкой; отказ сервера (нет примеров) показывается coral-text под кнопкой. Плитка «Карточки к повторению» на «Сегодня» показывает настоящее число или «—»; внутри ссылки-плитки `div`, а не `article`: контент `article` не попадает в доступное имя ссылки.

### Упражнения
Страница `/exercises` (пункт меню «Упражнения»): колонка до 3xl, заголовок Title. Одно упражнение за раз.

- **Карточка:** `.surface` (`article`, `aria-label="Упражнение"`), фокус на ней при появлении (в ручном вводе до ответа в поле), чтобы работали клавиши. Сверху тема 14px приглушённая, затем английское предложение 20px с пропуском (плашка surface-muted с `_____`, `role="img"`) и русский перевод 16px приглушённый.
- **Плитка варианта ответа:** кнопка 48px+, рамка 1px `--input`, скругление 12px, номер в `kbd` 24px (клавиши 1–4, скрыт от скринридера, клавиша в `aria-keyshortcuts`) и текст варианта. Сетка в одну колонку, от `sm` в две; hover заливка muted.
- **Верно / неверно** не только цветом. Верный вариант: рамка и галочка `--grass-text` (светлая #2d7a56, 5,2:1 на белом; тёмная #52b788, 6,3:1 на карточке), заливка muted, «верно» в `sr-only`. Выбранный неверный: рамка coral, текст coral-text, крест, «твой ответ» в `sr-only`. Остальные бледнеют (`opacity-60`), все плитки неактивны. В пропуске появляется верный ответ в `<mark>`.
- **Результат:** постоянный живой регион (`role="status"`, пуст до ответа). Внутри «Верно» или «Неверно» с иконкой, «Верный ответ: …» (только при ошибке), перевод и «Затронуто: Артикли 1523». Фокус после ответа остаётся на карточке.
- **«Дальше»:** жёлтая кнопка (Пробел или Enter); пока грузится следующее упражнение, подпись «Подбираем…».
- **Ручной ввод** (пустой список вариантов): поле «Твой ответ» 44px и кнопка «Ответить».
- **Состояния:** «Подбираем упражнение…»; пустое («Подходящих упражнений пока нет», «Попробуй позже или поменяй уровень в настройках» и кнопка «Настройки»); ошибка загрузки с «Повторить». Ошибка ответа в рамке coral: после сетевой ошибки или 5xx выбор заблокирован, кнопки «Повторить» (тот же ключ) и «Пропустить» (следующее без ответа); после 409 и 404 кнопка «Дальше».

**Порядок слов** (`kind: order`, тема `skill:order`, компонент `OrderExercise`): в карточке вместо английского предложения русское 20px (`lang="ru"`), перевод отдельной строкой не повторяется. Ниже «Твой ответ» (14px/600) и строка ответа: рамка 1px, скругление 12px, пунктир `--input`, пока ответа нет, подсказка «Нажимай на слова ниже»; после ответа рамка `--grass-text` с галочкой или coral с крестом (итог словами остаётся в живом регионе). Плитка слова: кнопка от 44px, рамка 1px `--input`, скругление 12px, `lang="en"`, у плитки в банке номер в `kbd` 20px (1–9, десятая — 0; `aria-keyshortcuts`), hover muted, нажатие `scale(0.97)`. Использованная плитка в банке остаётся на месте пунктирной пустой ячейкой (раскладка не прыгает), слово в строке ответа называется «убрать …». Клавиши: цифры переносят, Backspace убирает последнюю, Esc очищает, Enter отправляет, когда использованы все плитки (рядом кнопка «Проверить»). Движения плиток нет: действие клавишное и частое. Первое слово приходит строчным, завершающей точки нет; верный порядок после ответа показан в «Верный ответ: …».

**Выбор формы** (`kind: form`, тема `skill:form`, компонент `AddToCards`): та же карточка, что у пропуска (плитки вариантов 1–4, живой регион, «Дальше»). Под английским предложением отдельной строкой подсказка с начальной формой в скобках, «(go)», 16px приглушённым цветом, без жирности и не заголовок; для скринридера скобки скрыты (`aria-hidden`), вместо них читается «начальная форма: go» (`sr-only`). Перевод идёт строкой ниже. В результате, после «Затронуто», кнопка «Добавить в карточки» (secondary, sm, плюс слева), только если `word.inCards === false` (данные приходят в ответе на ответ, только у `form`). После успеха она превращается в неактивную ghost-кнопку «В карточках» с галочкой (такая же, как на странице «Слова»); при `inCards === true` сразу показывается только она. Отказ сервера (`no_examples`, у слова нет примеров) показывается coral-text под кнопкой, кнопка остаётся доступной. Фокус остаётся на карточке: у кнопки `onMouseDown` с `preventDefault`, поэтому клик мышью не забирает фокус и Пробел и Enter ведут к следующему упражнению; с клавиатуры кнопка по Tab и Enter срабатывает как обычная. Движения нет: ни у подсказки, ни у смены подписи кнопки (действие следует за клавишным ответом).

**Полоса слабых тем:** отдельная `.surface` под упражнением, заголовок 14px/600 «Слабые темы» и список из пяти тем с наименьшим рейтингом, строки разделены линией `--border`: русское название 16px/600 слева, справа рейтинг числом (600) и «· надёжность: высокая / средняя / низкая» 14px приглушённым (по отклонению рейтинга: до 100, до 200, выше). У темы с менее чем пятью ответами вместо надёжности стоит «мало ответов»; без данных: «Пока нет данных — ответь на несколько упражнений». Незнакомые ключи тем показываются как есть.

**Повтор ошибки:** если у упражнения `repeat: true`, над строкой темы стоит ярлык «Повтор ошибки» (14px/600, приглушённый цвет, без сигнального цвета, без иконки). В живом регионе результата, после «Затронуто», одна строка 14px приглушённая (`data-mistake`): «Ошибка закрыта» (верный ответ, статус `closed`), «Ещё один верный ответ, и ошибка закрыта» (верный, статус `open`) или «Вернётся завтра» (неверный ответ: новая ошибка или повтор). Без `mistake` в ответе строки нет. Движения нет: действие клавишное.

### Ошибки
Страница `/mistakes` (пункт меню «Ошибки»): колонка до 3xl, заголовок Title. Три числа в `dl` (сетка в три колонки от `sm`, каждое в `.surface` 16px): подпись 14px приглушённая («Открыто», «Ждут повтора сейчас», «Закрыто за неделю»), число 24px/600 `tabular-nums`. Ниже открытые ошибки по темам: на тему одна `.surface` с заголовком 14px/600 приглушённым (русское название темы) и списком, строки разделены линией `--border`. Строка: предложение 18px (для `order` русский перевод, `lang="ru"`), «Твой ответ: …» и «Верно: …» 14px (ответ 600), затем «ждёт повтора» / «вернётся завтра» / «через N дн.» и «Серия 1 из 2» 14px приглушённым. Сигнальных цветов и иконок нет: ошибка здесь материал для работы, не наказание. Пустое состояние: одна `.surface` с текстом «Пока ошибок нет. Ошибки из упражнений появятся здесь и вернутся через день». Состояния: «Загружаем ошибки…», ошибка с «Повторить», 401 ведёт на вход. Тексты из базы только текстом. Движения нет.

### Плашка демо-данных
`role="note"`, пунктирная 1px рамка field-border, белая заливка, скругление 12px, 14px/600. Нейтральная, не жёлтая.

## Do's and Don'ts

### Do:
- **Do** одна жёлтая кнопка на экран; жёлтый только для опыта и главного действия.
- **Do** показывать неопределённость дизером и честной подписью («Собираю данные»), а не выдуманной датой.
- **Do** использовать для заголовков и чисел Onest 700, для остального 400/600.
- **Do** строить карточки классом `.surface`: рамка 1px, скругление 16px, мягкая тень.
- **Do** брать иконки навигации из lucide: 20px, штрих 1.75, `aria-hidden`.
- **Do** оставлять пиксель-арт только логотипу, маскоту, флагам и дизеру; контур через `--pixel-ink`.
- **Do** проверять обе темы; акцентный текст, мост и контур пиксель-арта имеют тёмные варианты.
- **Do** помечать демо-данные нейтральной пунктирной плашкой.
- **Do** выключать анимации под `prefers-reduced-motion`.
- **Do** показывать срок вилкой с пометкой, что это оценка, а не точной датой.

### Don't:
- **Don't** красить коралловым что-либо кроме ошибок; не брать голубой для кнопки главного действия.
- **Don't** вводить вторую гарнитуру или пиксельный шрифт для заголовков и кнопок.
- **Don't** рисовать прогресс кольцом или процентной полосой вместо сегментов.
- **Don't** тащить пиксель-арт в обычные элементы: кнопки, поля, рамки, иконки меню.
- **Don't** использовать жёсткие смещённые тени.
- **Don't** повторять шаблон учебного дашборда с кольцом прогресса и детскую мультяшность.
