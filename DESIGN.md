# Design System: Verst

## Overview

**Creative North Star: "Пиксельный квест"**

Мир закреплён пользователем. Путь в языке нарисован как карта этапов: уровни A1…C1 стоят платформами, пройденные зелёные, текущий голубой с маскотом «Верста» (полосатый столбик-веха с лицом), путь до цели покрыт точечным растром. Всё построено из клеток 4px: контуры, тени, иконки, сегменты шкалы. Углов нет, размытия нет, переходов нет, есть только кадры.

Интерфейс на русском, на «ты». Плотность умеренная: крупные блоки с толстым контуром, много воздуха между ними, числа большие и растровые. Пиксельный шрифт держит только заголовки страниц, числа и кнопки; читаемый текст набран Onest.

Отвергнутое по факту: шаблон учебного дашборда с кольцом прогресса и мягкими белыми карточками.

**Key Characteristics:**
- Сетка 4px, контур 4px, прямые углы (`--radius: 0`).
- Жёсткие тени без размытия, смещение по сетке.
- Цвета с одной задачей; две темы (бумага и ночь) с одним набором ролей.
- Неопределённость и сила темы рисуются дизером, а не градиентом и не процентом.
- Движение покадровое, `steps(2)`.

## Colors

Ночной синий и бумага как каркас, четыре сигнальных цвета, каждый с единственной задачей.

### Primary
- **Солнечный жёлтый** (sun, #ffd23f): только опыт и главное действие: кнопка по умолчанию, активный пункт меню, заполненные сегменты шкалы опыта, выделение текста. Не для декора и не для предупреждений.

### Secondary
- **Небесный голубой** (sky, #4cc9f0): «ты здесь»: платформа текущего уровня; в тёмной теме и на тёмной панели ещё и кольцо фокуса. Акцентная кнопка (accent) использует его же.
- **Трава** (grass, #52b788): пройдено. Платформы и флаги пройденных уровней.
- **Коралл** (coral, #ef476f): только ошибки: контур поля с `aria-invalid`, рамка сообщения об ошибке, иконка и счётчик ошибок. Для текста коралл темнее (coral-text, #c42d52; в тёмной теме #ff8fa8, чтобы держать 4.5:1). Заливка опасной кнопки светлее (coral-soft, #ff6b88): на ней чернильный текст читается.

### Neutral
- **Ночные чернила** (ink, #1e2347): текст, контур и тень в светлой теме, левая панель, кольцо фокуса в светлой теме.
- **Бумага** (paper, #f7f7ff): фон светлой темы. Карточки белые (#ffffff).
- **Ночь** (night, #14172e): фон тёмной темы; карточки #1e2347, панель #0f1126, тень #0a0c1c.
- **Приглушённая поверхность** (surface-muted, #e4e6f7; тёмная #2a3060): пустые сегменты шкалы, будущие платформы, hover на вторичных элементах.
- **Приглушённый текст** (text-muted, #4b5388; тёмная #a9b0e0): подписи и подсказки. Контур в тёмной теме светлеет до #6e78b8.
- **Мост** (bridge, #2d7a56; тёмная #8fd3b0): точки дизера на «неопределённом» участке пути; обычная трава тонет на платформе.

### Named Rules
**The One Job Rule.** Каждый сигнальный цвет значит одно. Жёлтый не метка «демо» и не предупреждение; коралл не акцент и не декор; зелёный не «успех кнопки».
**The Ink Focus Rule.** Кольцо фокуса: ink в светлой теме, sky в тёмной и на тёмной панели.

## Typography

**Display Font:** Press Start 2P (ui-monospace, monospace), локально через Fontsource
**Body Font:** Onest (system-ui, sans-serif), веса 400 и 600

**Character:** Растровая вывеска над спокойным гротеском. Pixelify Sans в брифе был отвергнут из-за плохой кириллицы; в сборке Press Start 2P.

### Hierarchy
- **Display** (400, 2.5rem, 3rem): большие числа на карточках задач и серия на широком экране.
- **Title** (400, 1.5rem, 2rem): заголовок страницы и блока («Привет, …», «Твой путь», «Вход»).
- **Button** (400, 1rem; sm 0.875rem): подписи кнопок.
- **Body** (Onest 400, 1rem, 1.5rem): основной текст.
- **Label** (Onest 600, 0.875rem): заголовки малых карточек, подписи, пункты меню (16px/600), подсказки (14px/400).

### Named Rules
**The One Weight Rule.** У пиксельного шрифта один вес; жирный и курсив запрещены (подделка). Класс `font-pixel` включается явно, пробел сужен (`word-spacing: -0.3em`).
**The Pixel Scope Rule.** Пиксельный шрифт только для заголовков страниц, чисел и кнопок; абзацы, подписи и навигация в Onest. Размеры пиксельного шрифта кратны 8 (16, 24, 40) для чёткости.

## Layout

Гибкая вёрстка без фиксированной ширины, сначала десктоп. Шаг 4px (один шаг Tailwind), основной ритм 8/16/24/32. Каркас: слева панель 240px (от `lg`, 1024px), ниже сжимается до 80px с одними иконками; рабочая область занимает остаток. Экран «Сегодня»: сетка в одну колонку, от `xl` (1280px) добавляется правая колонка 20rem с серией, минимальным днём и главной кнопкой; три карточки задач в ряд от `md`. Отступы страницы 24px, от `xl` 32px. Вход: центрированный блок до 28rem. Ссылка «Перейти к содержимому» первой в порядке фокуса. Числа в таблицах и подписях с `tabular-nums`.

## Elevation & Depth

Глубина только жёсткая тень без размытия, смещённая по сетке; тональных слоёв нет.

### Shadow Vocabulary
- **Pixel** (`box-shadow: 4px 4px 0 0 var(--shadow)`): блоки, кнопки, карточки.
- **Pixel small** (`2px 2px 0 0 var(--shadow)`): нажатая кнопка, активный пункт меню.
- **Pixel hover** (`6px 6px 0 0`): карточка-ссылка при наведении.
- **Pixel inset** (`inset -4px -4px 0 0 rgb(0 0 0 / 0.18), inset 4px 4px 0 0 rgb(255 255 255 / 0.4)`): объявлен в токенах, в просмотренных экранах не применён.

Цвет тени: ink в светлой теме, #0a0c1c в тёмной.

### Named Rules
**The Hard Shadow Rule.** Тень без размытия, смещение кратно 2–4px и по диагонали вниз-вправо. Мягкие тени запрещены.

## Shapes

Прямые углы везде (все радиусы 0). Контур 4px (`--line`), у платформ только верх и низ. Недоступное и «честная заметка» рисуются пунктирным 4px контуром (disabled: пунктир без тени и приглушённая заливка). Графика (иконки, флаги, маскот, логотип) строится из клеток и отображается `image-rendering: pixelated`.

## Components

Все блоки: контур 4px, прямые углы, жёсткая тень.

### Buttons
- **Shape:** прямоугольник, 4px контур, 48px высота (sm 40px, lg минимум 56px, icon 48px), шрифт пиксельный.
- **Primary:** sun с ink-текстом, отступ 24px по бокам. Одна на экран.
- **Secondary / Accent / Destructive / Ghost / Link:** белая заливка; sky; coral-soft; прозрачная с контуром на hover; ссылка с подчёркиванием.
- **Hover / Active:** `brightness-105` или hover-заливка; при нажатии кнопка сдвигается на 4px и тень уменьшается (вдавливание). Переходов нет.
- **Disabled:** пунктирный контур, приглушённая заливка, без тени.

### Inputs / Fields
- **Style:** 48px, белая заливка, 4px контур ink, отступ 16px, прямые углы.
- **Focus:** общее кольцо `outline: 4px solid var(--focus)`, offset 2px.
- **Error:** контур коралловый; сообщение: рамка 4px coral, текст coral-text.

### Cards / Containers
- **pixel-box:** белая (тёмная #1e2347) заливка, 4px контур, тень Pixel, отступ 16–24px.
- **Карточка задачи:** целиком ссылка; иконка, заголовок 14px/600, число Display, подсказка. Hover: сдвиг на -2px и тень 6px за 100 мс `steps(2)`; нажатие +2px. Карточка ошибок красит иконку в coral-text.

### Navigation
Левая панель цвета ink (rail), слово VERST на земле сверху, пункты 48px: иконка 9×9 в масштабе 3 + подпись Onest 600. Активный: жёлтая заливка, ink-текст, тень Pixel small. Неактивный: приглушённый текст `#a9b0e0`, на hover контур. Ниже 1024px остаются иконки (подписи для скринридера). Внизу пользователь, переключатель темы, выход.

### Шкала опыта (XpBar)
Контейнер с 4px контуром и сегментами по 4px зазором; заполненные sun, пустые приглушённые. 10 сегментов для минимального дня, 20 для опыта уровня. Это единственное место для прогресса: колец и процентных полос нет.

### Карта этапов (StageMap)
Пять платформ A1…C1 встык: пройденные grass, текущий sky с маскотом (подпрыгивает на 4px, `steps(2)`), участок до цели приглушённый с дизером (bridge), остальное приглушённое. Над платформой флаг; подписи «Пройден», «Ты здесь», «Цель».

### Дизер (Dither)
Маска 8×8 из клеток 4×4, пять ступеней плотности 0…4 (0 пусто, 2 шахматка, 4 сплошная), цвет текущий. Назначение: неопределённость (путь без прогноза) и сила темы.

### Иконки, маскот, логотип
Иконки нарисованы клетками 9×9 цвета текущего текста (сегодня, карточки, упражнения, слова, ошибки, прогресс, контраст, выход), масштаб 3. Логотип «1A Платформер»: слово VERST стоит на земле; в малом размере столб без лица. Маскот «Верста».

### Плашка демо-данных
`role="note"`, пунктирный 4px ink-контур, белая заливка, 14px/600. Помечает данные-заглушки, не жёлтая.

## Do's and Don'ts

### Do:
- **Do** строить размеры, отступы, тени из шага 4px и контура 4px.
- **Do** одна жёлтая кнопка на экран; жёлтый только для опыта и главного действия.
- **Do** показывать неопределённость дизером и честной подписью («Собираю данные»), а не выдуманной датой.
- **Do** рисовать новые иконки клетками 9×9 в `currentColor`.
- **Do** двигать только покадрово, `steps(2)`; при `prefers-reduced-motion` оставлять статичный кадр.
- **Do** помечать демо-данные пунктирной ink-плашкой.
- **Do** проверять оба режима темы: акцентные тексты и мост имеют тёмные варианты.

### Don't:
- **Don't** использовать скругления, размытые тени, градиенты и плавные переходы.
- **Don't** красить коралловым что-либо кроме ошибок; не брать голубой для кнопок «главного действия».
- **Don't** применять Press Start 2P для абзацев и меню; не делать его жирным или курсивным.
- **Don't** рисовать прогресс кольцом или процентной полосой вместо сегментов.
- **Don't** подключать иконки из шрифтов или пакетов-глифов, вместо нарисованных клеток.
- **Don't** повторять шаблон учебного дашборда: белые мягкие карточки, кольцо прогресса.
